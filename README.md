# Raw-Website-Login-Page
A community-driven HTML and CSS login page focused on modern design, glass morphism, and responsive styling.
About my project
Project name: Katso Login Page
Technologies: HTML and CSS
I already have my own index.html and style.css files.
My design includes a background image, a header with three navigation links, a login form, email and password fields, a login button, and Google, GitHub, and Facebook icons.
I am learning how to style the page with CSS, including glassmorphism, blur effects, hover animations, and responsive design.
My goal

I want to publish this project on GitHub as a public open-source repository so other people can:

Improve the design and make it more beautiful.
Create new themes, colors, backgrounds, and animations.
Improve the mobile layout.
Suggest ideas and report bugs.
Contribute their own HTML and CSS through pull requests.
